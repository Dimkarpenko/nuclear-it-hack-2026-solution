# HEX Mesh Chat

Hackathon project: local-first messenger inspired by Telegram UX, focused on LAN/mesh delivery, resilience, and secure pairing.

## Stage Plan

1. Initialization and app foundations
2. Domain models and local persistence
3. Device identity and secure pairing
4. Local discovery and signaling
5. Reliable messaging protocol (ACK/retry/dedupe/TTL)
6. Private chat UI and sync
7. Chunked file transfer (50-200 MB)
8. Voice/video calls
9. Security hardening
10. Logs, metrics, demo mode

## Commands

- `npm run start`
- `npm run android`
- `npm run web`
- `npm run typecheck`

## Current Status

Initialization complete: Expo + TypeScript + Navigation app shell.
